# Enagic Webhook Integration

## Description
This project integrates Enagic with Slack via webhooks. It listens for incoming events and posts updates to a Slack channel.

## Setup Instructions
1. Clone this repository: `git clone <your-repo-url>`
2. Navigate into the directory: `cd enagic-webhook`
3. Install dependencies: `npm install`
4. Create a `.env` file and add the required environment variables (see `.env` below).
5. Deploy to Render and set the **Start Command** to `node server.js`
